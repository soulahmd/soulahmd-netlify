# Soulahmd Portfolio

A cinematic personal portfolio for Ahmed Sabith (Soulahmd), an AI video creator, digital marketer, and founder of Evoq.ai. The site presents his services, professional story, collaborations, featured campaign work, achievements, and contact channels in a responsive, streaming-inspired experience.

## Technology

- TanStack Start and TanStack Router
- React 19 and TypeScript
- Vite 7
- Tailwind CSS 4 with a custom global design system
- Lucide React icons
- Netlify deployment adapter

## Local Development

Install dependencies and start the local development server:

```bash
pnpm install
pnpm dev
```

The standard Vite server runs on port `3000`. For Netlify platform emulation, use Netlify Dev on port `8889`.

## Key Files

- `src/routes/index.tsx` — the complete portfolio page and achievement lightbox
- `src/styles.css` — visual system, layout, animation, and responsive behavior
- `public/images/` — project photography and recognition artwork
- `src/routes/__root.tsx` — document metadata and root shell

## Contact Links

The project CTA uses direct email, WhatsApp, and Instagram links so visitors can contact Ahmed without an account or form workflow.
